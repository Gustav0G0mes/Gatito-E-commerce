# 🐱 Dashboard E-commerce Gatito - Métricas & Indicadores Comercial

Painel de inteligência comercial e análise de dados desenvolvido no **Google Looker Studio** para a empresa fictícia **Gatito e-commerce**. O objetivo deste projeto é monitorar o desempenho financeiro, evolução do volume de vendas, lucratividade e acompanhamento da força de vendas.

## 💡 Visão Geral

Este projeto foi desenvolvido para oferecer uma visão estratégica e operacional sobre as operações do e-commerce. 

Através de uma interface limpa em Dark Mode, o painel centraliza o acompanhamento financeiro geral da empresa e permite avaliar a produtividade do time comercial, com comissionamento e volume de transações por período.

## 🎯 Métricas e KPIs Principais

| **Indicador** | **Valor Total** | **Descrição** |
| :--- | :--- | :--- |
| **Faturamento Total** | **R\$ 359.309,11** | Volume financeiro total gerado pelas vendas |
| **Custo de Operação** | **R\$ 90,00** | Custos operacionais diretos registrados |
| **Lucro Bruto** | **R\$ 298.644,11** | Retorno financeiro acumulado das operações |
| **Total de Vendedores** | **9 Vendedores** | Tamanho da equipe comercial ativa |

## 🖥️ Destaques do Dashboard

### Página 1: Visão Geral de Performance

* **Evolução Temporal Acumulada:** Gráfico de tendência em linha mostrando o crescimento contínuo de receita da empresa.
* **Consolidação Financeira:** Cartões de destaque com Receita, Custo e Lucro Bruto para tomada de decisão rápida.

### Página 2: Indicadores da Equipe de Vendas

* **Performance da Equipe:** Contagem de vendedores ativos e cálculo geral de comissionamento.
* **Volume de Transações por Data:** Gráfico temporal de barras com a frequência de vendas para identificação de picos de demanda e sazonalidade.

## 🛠️ Tecnologias Utilizadas

* **Google Looker Studio:** Modelagem de dados e criação das visualizações interativas.
* **Google Sheets / CSV:** Base de dados utilizada para alimentações das transações comerciais.
* **Análise de Dados:** Criação de métricas agregadas e cálculos de comissão.
